    Utilizo varios programas, tanto para mis videos como para mis otros trabajos:

  • DAVINCI RESOLVE para editar el video, hacer VFX y editar audio.
  • FLAMESHOT para hacer capturas de pantalla en el PC.
  • GIMP para las miniaturas, y para editar los assets de mis videojuegos.
  • GIT para el control de Versiones de mis trabajos.
  • GODOT para mis videojuegos.
  • INKSCAPE para dibujos vectoriales.
  • KRITA para dibujar y animar esos dibujos.
  • LMMS para componer música.
  • OBS STUDIO para hacer mis videos y directos.
  • PIXELORAMA para hacer Pixel Art.
  • VEADOTUBE MINI para mis avatares PNG.
