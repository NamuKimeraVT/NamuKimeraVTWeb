QUE PROGRAMAS UTILIZAS Y PARA QUE FUNCIONES?
Utilizo varios programas, tanto para mis videos como para mis otros trabajos:
  • AFTER EFFECTS para Motion Graphics, VFX y animar los emotes.

  • ANIMATE para Animaciones (HTML 5, PIXIJS).

  • ASEPRITE para hacer Pixel Art.

  • AUDITION para grabar y editar el audio de mis videos.

  • BLENDER para modelado 3D.

  • CLIP STUDIO PAINT para hacer dibujos que no puedo en KRITA.

  • FLAMESHOT para hacer capturas de pantalla en el PC.

  • GB STUDIO para videojuegos para Game Boy.

  • GODOT para mis videojuegos.

  • ILLUSTRATOR para dibujos vectoriales.

  • INOCHI para Rigging de VTubers 2D.

  • KRITA para dibujar y animar esos dibujos.

  • LMMS para componer música.

  • MEDIA ENCODER para exportar mis videos.

  • OBS STUDIO para hacer mis videos y directos.

  • PHOTOSHOP para las miniaturas, y para editar los assets de mis videojuegos.

  • PREMIERE PRO para editar videos.

  • SOURCETREE para el control de versiones de mis trabajos.

  • SUBSTANCE 3D DESIGNER para crear materiales PBR procedurales.

  • SUBSTANCE 3D PAINTER para pintar y aplicar texturas.

  • VEADOTUBE MINI para mis avatares PNG.

  • VISUAL STUDIO CODE para programar alguna que otra cosa.
